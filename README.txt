Handwritten Mark Extractor - Portable Setup
=============================================

FIRST TIME ON A NEW COMPUTER:
  1. Copy this whole folder to the computer (or run it straight off the USB drive).
  2. Double-click setup_install.bat and let it finish.
     - If it says Python was just installed, run setup_install.bat a second time.
  3. Double-click start_app.bat to launch the app - it opens in your browser.

EVERY TIME AFTER THAT:
  Just double-click start_app.bat.

CHANGING YOUR API KEY:
  Open the app, go to the "Settings" tab, paste the new key, click Save and apply.
  No restart needed - takes effect immediately, and is remembered next time too.

NOTES:
  - The "Parent folder" you set in the Customer Batches tab is specific to each computer -
    you'll need to point it at wherever your SV1-SV13 folders live on THIS machine.
  - Your OpenAI API key lives in the .env file in this folder in plain text. Treat this
    folder/drive like you would any other copy of a paid credential.
